# Проект «Арканум»

## Цель домашнего задания
Создание базовой структуры Django-проекта: настройка маршрутизации, использование шаблонизатора, реализация пагинации и подготовка рабочего окружения (Docker).

## Что было сделано
1. Создание view-функций, отображающих «рыбу» (главная страница, страница вопросов).
2. Настройка маршрутизации URL (файлы urls.py).
3. Использование шаблонизатора Django (наследование от base.html, использование include для карточек).
4. Постраничное отображение (пагинация) для списка вопросов.
5. Настройка рабочего окружения (Dockerfile, docker-compose.yml).

### Доделано
- Страница регистрации и страница входа.
- Страница просмотра вопросов по тегу (маршрут вида /tag/название_тега/).
- Страница настроек профиля пользователя.

Страница настройки профиля:
Чтобы увидеть страницу настроек пользователя, откройте файл base.html, строка с условием `{% if user.is_authenticated %}` ( 30-я строка) и временно замените её на `{% if 1 %}`. После этого в шапке появится аватар и кнопка «Настройки», ведущая в профиль. Не забудьте вернуть всё как было после проверки.

## Инструкция по запуску

Проект можно запустить двумя способами: локально (через виртуальное окружение) или в изолированном контейнере (через Docker).

### Вариант 1: Локальный запуск (через venv)

1. Создайте и активируйте виртуальное окружение:
   bash
   python -m venv .venv
   
   ### Для Windows:
   .venv\Scripts\activate
   
   ### Для Mac/Linux:
   source .venv/bin/activate

2. Установить зависимость
   pip install -r requirements.txt
3. Запустить сервер
  python manage.py runserver

### Вариант 2: Запуск через Docker Compose

1. Соберите и запустите контейнеры (находясь в корневой папке проекта, где лежит файл docker-compose.yml):
  docker compose up --build

3. Дождитесь, пока контейнер соберется (скачает образ Python и установит зависимости) и запустится сервер.

4. Откройте в браузере: http://127.0.0.1:8000/
