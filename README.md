# Домашнее задание №1 - Верстка статического сайта

## Страницы проекта
В проекте реализованы следующие страницы (роуты):
- `index.html` — Основная (главная) страница сайта;
- `ask.html` — Страница для задания нового вопроса;
- `question.html` — Страница просмотра одного вопроса (с ответами);
- `profile.html` — Страница пользователя (профиль).
