## Домашнее задание №4

* **Архитектура:** Логика авторизации, регистрации и профиля перенесена в отдельное приложение `core` (views, forms, urls, шаблоны).
* **Безопасность (next):** В форму и view логина добавлена безопасная обработка параметра `?next=` с защитой от Open Redirect (`url_has_allowed_host_and_scheme`).
* **Валидация пароля:** В форму регистрации добавлена проверка пароля через `AUTH_PASSWORD_VALIDATORS` с выводом ошибок.
* **Формы:** Все формы наследуются от `ModelForm`; логика сохранения (автор, теги) вынесена в методы `save()` форм.
* **Медиа:** Настроены `MEDIA_URL` и `MEDIA_ROOT`, добавлена модель `ImageModel` для загрузки и отображения аватарок и картинок к вопросам.
* **AJAX-запросы:** Реализованы лайки вопросов и ответов без перезагрузки страницы (возврат JSON, передача CSRF-токена).
* **Галочка «Правильный ответ»:** Реализована через AJAX с проверкой, что выбор доступен только автору вопроса.

## Инструкция по запуску (через Docker)

### 1. Запуск проекта
Откройте терминал в папке с проектом и выполните команду:
``` docker-compose up --build ```
В корне проекта создайте файл **`.env.docker`** и вставьте в него настройки из  **`.env.example`** 

### 2. Заполнение базы данных тестовыми данными
Откройте терминал (не закрывая тот, где работает Docker) и выполните команду для генерации данных:
```docker-compose exec web python manage.py fill_db 100```
При ratio = 100 создаст 100 пользователей, 1000 вопросов, 10 000 ответов и 20 000 лайков.

### 3. Создание суперпользователя (для входа в админку)
Чтобы получить доступ к панели администратора (`/admin/`), создайте суперпользователя:
```docker-compose exec web python manage.py createsuperuser```

## Локальный запуск

### 1. Настройка окружения
В корне проекта создайте файл **`.env.local`** и вставьте в него настройки из  **`.env.example`** 


### 2. Запуск
Убедитесь, что у вас локально установлен и запущен PostgreSQL, создана база данных. Затем в терминале:

```pip install -r requirements.txt```

```python manage.py migrate```

Для заполнения базы данных

```python manage.py fill_db 100```

Для получения доступа к панели администратора

```python manage.py createsuperuser```

Для запуска сервера

```python manage.py runserver```
